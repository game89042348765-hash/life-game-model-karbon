# Инструменты текущей лаборатории LifeGame

12 ноября 2026, LAB-013. **51 позиция: инструменты и возможности**, сверены по коду. Это каталог personal-lab/ и двух явно отмеченных экспериментов; основная personal/ этими изменениями не обновлялась. [Машиночитаемый список, точки кода и хеши](APP-TOOLS.json).

Единица списка — пользовательский инструмент или поддерживающая возможность. Карточки будущего атласа имеют другую детализацию: соответствие может быть многие-ко-многим. Доступность инструментов зависит от Lite, выбранного режима и контекста. Наличие кода не заменяет пользовательскую приёмку.

Каталог нужен позднему APP-MAP. Широкий поиск «ГИДРЫ» продолжает работать по своим категориям; этот список не ограничивает исследователей. Новые пункты добавлять с новыми ID, существующие ID не перенумеровывать.
