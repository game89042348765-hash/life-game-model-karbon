# AI-контекст Personal — версия 1

Это новый формат чтения, не формат сохранения и не контракт импорта рекомендаций. API: LifeGameAIContext.build(state, options, source) → packet, request, characters. state не изменяется.

## Настройки

mode: daily / progress / strategy. format: text / plan / map. from/to: включительный период до текущей даты, максимум десять лет. maxChars: 6000–180000 знаков UTF-16; UI предлагает 20000/60000/120000. detail: compact либо full. blockIds: явно выбранные ID; пустой список остаётся пустым. unbound: самостоятельные дела. archives: включать архив.

include: strategy, actions, history, reflections, economy, locations, inbox. По умолчанию включены первые три. Неизвестная энергия, голос и ответы AI не дописываются.

source: today, now при фиксации времени, timezone, space, offset, plan. В интерфейсе используются фактический день и текущее пространство Personal. plan — результат существующей dayPlan, а не новый алгоритм планирования. Сборщик не вызывает обработку дней и не вычисляет отсутствующий исторический знаменатель.

## Пакет

format=lifegame-ai-context; version=1.

meta содержит дату генерации UTC, часовой пояс, продукт/модель/revision, пространство, текущий день и тестовый сдвиг, период, режим, форму ответа, выбранные направления, исключения, подробность и лимит. coverage показывает число отобранных исходных строк, вошедших строк и усечённых подробностей по таблицам.

records содержит только разрешённые разделы:

- blocks/stages/goals — выбранный текущий снимок стратегии, исходные ID и связи;
- actions — действия с kind/source_collection, реальными расписаниями, нормами, календарными исключениями; описания включаются в full;
- facts/time/misses/days — относящиеся к scope записи в периоде; флаги отмены сохраняются;
- current_plan — текущий видимый/скрытый план и причины, только в daily при включённых actions;
- reflections/motivation — собственные ответы sessions и настройка мотивации, только после включения и при полном scope;
- ledger/inbox — отдельно включённые глобальные записи, только при полном scope;
- locations — отдельно включённые названия/связи; без них поля места в фактах/действиях исключены.

aggregates рассчитываются по разрешённым исходным строкам периода до сокращения подробностей: активные отметки по kind, отменённые отметки, записанные минуты, сохранённые пропуски по статусу; отдельно выбранная игровая экономика периода. HabitStep — подход, habit — успешный день. QuestStep и QuestFinal не объединяются в число выполненных задач.

## Исключения и усечение

Связанные записи исключённых направлений не передаются. История без существующего разрешённого источника не восстанавливается догадкой. При частичном scope глобальные свободные ответы/входящие/экономика исключаются целиком; соответствующая причина видна в meta.excluded_categories. Имена, случайно упомянутые внутри разрешённого свободного текста, семантически не редактируются.

В компактном режиме описания отсутствуют явно. История сортируется от новой к старой. При превышении лимита сокращаются целые строки подробностей, сохраняя агрегаты и coverage. Сама стратегия/действия не обрезаются до некорректных связей: если они слишком велики, сборка возвращает понятную ошибку. request всегда содержит полный JSON либо не создаётся.

Факты могут ссылаться на существующий источник, подробности которого не экспортировались из-за выбранных категорий. source ID — ссылка в оригинальную Personal, а не утверждение о наличии всех объектов в пакете. Идентификаторы в рефлексии не извлекаются автоматически.

## Статусы знания

facts означают зарегистрированные отметки приложения; session answers — личные свидетельства. Отмена отражает текущее состояние отметки и не всегда позволяет восстановить момент отмены. Модель должна отдельно перечислять проверяемые выводы, гипотезы и предлагаемые изменения, с ID оснований. Любые предложенные действия исполняются человеком вручную.

Метаданные и ID помогают воспроизвести состав контекста; они не удостоверяют истинность жизненных событий. Ни красивый граф, ни уверенный ответ модели не меняют эту границу.
