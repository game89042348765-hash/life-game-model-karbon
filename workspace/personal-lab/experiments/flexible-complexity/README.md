## Открыть

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000/personal-lab/experiments/flexible-complexity/ . Нужен HTTP, двойной щелчок по HTML не подходит для PWA. Код находится в ветке `lab/synthetic-users`; push этой ветки не публикует эксперимент в GitHub Pages основной main.

## Попробовать за пять минут

1. Выберите «Базовый», прочитайте короткое знакомство и закройте настройки. Можно оставить все опции выключенными и начать с пустого ритма.
2. Добавьте задание или ежедневную привычку кнопкой «Добавить в ритм». Отметьте выполнение, затем отмените: запись и награда используют общие механики Personal.
3. Откройте «Полный», через «Разделы → Привычки» создайте ещё одну привычку. Вернитесь в Базовый: новая привычка не добавится сама.
4. В «Настроить» выберите её вручную или попробуйте «Предложить небольшой набор». Предложение меняет только форму; до сохранения ритм прежний.
5. При желании включите календарь, выберите конкретные события, отдельно включите напоминания или статистику. Всё выключено по умолчанию.
6. Для полного возвращения ожиданий откройте Полный и выберите «Возобновить всю стратегию…». После подтверждения прежние расписания действуют **с завтра**, без долгов за дни заморозки. Повторный вход в Базовый отменяет ещё не наступившее возобновление.

Базовый можно использовать постоянно. Здесь нет кошелька, счётчика скрытых планов, пропусков или предложения «вернуться к развитию». Полный сохраняет прежние инструменты Personal; вход в него сам по себе оставляет ожидания Базового.

## Данные и проверка

- Свои ключи `lifegame-flex-lab-*`, Web Lock `lifegame-flex-lab-write`, кэш `lifegame-flex-lab-shell-v1` и scope папки. Автоматического чтения или переноса данных соседних приложений нет.
- Экспорт в Полном содержит общие факты, баланс, объекты и историю режимов. Старый Personal v2 без `flex` открывается в Полном. Старая Personal не умеет соблюдать новые правила паузы: её принятие JSON не означает семантическую совместимость.
- Проверки запускаются на вымышленных данных в временных браузерах, без платных API и внешних запросов:

```sh
python3 personal-lab/experiments/flexible-complexity/tests/verify.py
```

Артефакты сохраняются в игнорируемом `personal-lab/verification/LAB-009-<UTC>/`: отчёт, состояния до/после 90 дней, скриншоты и браузерная трасса. В поставляемом приложении диагностического API нет: тест добавляет его только в локальный HTTP-ответ.

Долгая пауза проверяется технически. Это не исследование независимых цифровых пользователей и не доказательство удобства для реальных людей. Ручная приёмка интерфейса и предложенных правил ещё предстоит.
