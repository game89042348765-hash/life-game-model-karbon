# LAB-013 — компактные снимки

[Базовый: записано пять минут, подходы ещё не отмечены](basic-five-minutes.png).

[Конструктор дня в Lite: те же минуты в строке привычки](lite-five-minutes.png).

Chromium, 390 px, полностью вымышленные данные. Для проверки сценариев служат BROWSER-TESTS/VERIFICATION и полные локальные traces; два снимка не являются самостоятельным UX-исследованием. Формат и значения интерфейса не означают, что приложение считает минуты дневной нормой: учёт времени и подходов разделены.
