## Открыть текущую копию

Из корня репозитория в ветке lab/synthetic-users:

```sh
python3 -m http.server 8041 --bind 127.0.0.1
```

В браузере **той же среды**:

- http://127.0.0.1:8041/personal-lab/ — родительская лаборатория;
- http://127.0.0.1:8041/personal-lab/experiments/flexible-complexity/ — Базовый/Полный;
- http://127.0.0.1:8041/personal-lab/experiments/ai-strategy/ — AI-контекст.

Установленные копии получат обычное предложение обновления PWA. Для каждой повышен свой кэш v1 → v2, данные/ключи сохранены. Основная Pages из main содержит прежнюю Personal; push lab-ветки не переносит туда эти изменения.

## Повторить техническую проверку

```sh
python3 -B personal-lab/tests/daily-ux.py
python3 -B personal-lab/experiments/ai-strategy/tests/verify.py
python3 -B personal-lab/experiments/flexible-complexity/tests/verify.py
```

Для проверки настоящего обновления v1→v2 первый сценарий читает точный исходник из Git-коммита 50bfec575c6d173be901fd60d38c1fc576668651. Нужна история этого репозитория. Тесты запускаются на localhost в отдельных временных Chromium, внешние запросы блокируются. Полные состояния/трассы находятся в игнорируемом verification/; в Git добавлены отчёты, хеши и два снимка вымышленных данных.

Это технические сценарии, не новый независимый AI-пилот и не человеческая приёмка. Дальнейшие шаги — ручная оценка удобства на телефоне, затем короткий AI-пилот на новом зафиксированном срезе. Прежние месячные артефакты/драйвер, «ГИДРА», её рабочий ZIP, root/Next/Personal и реальные данные не изменены.
