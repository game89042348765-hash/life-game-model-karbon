# Короткая ручная приёмка LAB-013

Сначала выберите лабораторную копию по README. Для пробы подходят вымышленные данные «Примера»; реальный прогресс сбрасывать не требуется.

1. Создайте привычку с одним подходом, отметьте и отмените. Понятны ли одна награда и её отмена? Подход не должен появляться отдельным выполнением «вне плана».
2. Создайте привычку с тремя подходами. Вместо полного выполнения запишите пять минут. Видны пять минут и прежнее число подходов; награда за одну запись времени не появляется. Достаточно ли понятен этот способ отметить частичное усилие?
3. Откройте запись времени ещё раз, исправьте 5 на 3. При ошибочной записи можно поставить 0. Проверьте, что не приходится угадывать, что теперь считается выполненным.
4. В Базовом оставьте пару своих действий. Запишите минуты прямо из ритма, откройте Полный для редактирования и вернитесь. Удобен ли маршрут без заполнения большой стратегии?
5. Завершите разовое задание, затем найдите его через быстрое выполнение. Видно ли, что запись сохранена и уже выполнена? Достаточно ли ясна разница между новым разовым делом и привычкой?

На телефоне особенно полезно проверить клавиатуру, видимость сохранения, размер нажатий и понятность сообщений. Технические viewport-проверки не заменяют это.

Обратная связь: что хотели сделать → где остановились → ожидание → фактический результат. Можно провести 3–4 обычных дня в выбранном варианте. Не нужно искусственно выполнять все сценарии ради процента успеха. Пользовательскую оценку записать отдельным дополнением, не менять технические результаты задним числом.
