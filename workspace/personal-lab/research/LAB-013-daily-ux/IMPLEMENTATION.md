## Изменения интерфейса и поведения

| Раньше | Сейчас |
|---|---|
| План нормализовал habitStep → habit, а список «вне плана» делал это иначе. | Оба места используют один factPlanRef. Подход сопоставляется с той же привычкой, шаг — с квестом, календарный факт — с номинальным появлением. Отдельная веха цели привычки по-прежнему показана отдельным событием. Факты и финансовый журнал не удаляются. |
| Для ввода уже потраченных пяти минут нужно было искать путь через таймер. | В карточке/меню активного дела и прямо в Базовом доступно «Записать время». Один ввод минут сохраняется в существующем timeLog. Итог виден в карточке, строке дела и дневной сводке. |
| Не было доступного в этом маршруте исправления неверного количества минут. | Через список времени за сегодня можно исправить сумму в той же записи. Значение 0 убирает минуты из итога, сохраняя ID записи; награды/выполнения не меняются. |
| Завершённое разовое дело исключалось из быстрого выполнения без пояснения. | По запросу показан блок «Уже завершено» с открытием исходной карточки. Новой отметки/награды он не делает. Создание другой записи обозначено явно. |

Минуты **не интерпретируются как доля дневной нормы**, текст названия не парсится как правило награды. Привычки по-прежнему считают подходы, а успешный день — полную заданную норму. Это полезный первый вариант учёта частичного усилия, не новый движок привычек в минутах.

## Сохранность

- Использован прежний timeLog: id, date, minutes, label, ref, ts. Формат v2 и personal-1 не менялся, persistence/экономика не переписывались.
- Новая запись: целое число 1–1440 минут; исправление: 0–1440. Только текущая дата и активные задания/привычки/квесты. Редактирование прошлых дат и минутная норма остаются отдельными возможными задачами.
- У формы есть устойчивый ID и защита повторной отправки. Ошибка записи откатывает изменение, сохраняет введённое значение и допускает повтор. Конфликт другой вкладки не заменяет её данные. Смена даты не переносит черновик на другой день незаметно.
- Если для того же дела есть открытый таймер, используется его прежнее подтверждение времени. Ручная форма не создаёт второй результат параллельно этому таймеру.
- В Базовом сохраняются членство ритма, политика паузы, отсутствие кошелька и нейтральная обратная связь. Запись времени не возобновляет замороженные планы.
