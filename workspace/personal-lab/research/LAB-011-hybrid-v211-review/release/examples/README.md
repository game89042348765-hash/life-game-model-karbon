# Только технические примеры

Все записи demo вымышлены. Домены example.invalid не являются источниками, accessed/verified/баллы заданы только для проверки структуры. Ни один источник не открывался и ни один механизм не исследовался. synthetic=true позволяет программе отделять эти данные от рабочего исследования.

demo содержит небольшой полный набор файлов. Это пример того, как связываются источники, находки, элементы, отображения и оценки. Имена и значения нельзя копировать в настоящий каталог. RUN.demo.json включает режим synthetic_demo; обычный research-расчёт отвергает такие записи.

Проверка tools/verify_tools.py создаёт также временный набор из 10 000 вымышленных элементов и 20 000 заданных оценок. Она проверяет вычисление и учёт, а не масштаб реально выполненного исследования. Набор удаляется вместе с временной папкой; в архиве нет фальшивого мирового топа.
