# LAB-014 — что подготовлено

**Дата:** 12 ноября 2026, Europe/Moscow. **Запрос:** сделать предложенный автономный пакет повторного пилота для внешней модели. **Исходник приложения/стенда:** 27919b94a7e7bb5f038dbb5235b79ea89b29c916. Исполнитель — координатор, новые внешние модели/Arena/API не запускались. Точные исходные ресурсы и SHA — SOURCE.json, окончательный ZIP — PACKAGE.json.

## Выбор объёма

Основной объект — Базовый/Полный с общими правками LAB-013, поскольку следующий продуктовый вопрос касается короткого ежедневного маршрута. Остальные копии и старые результаты не смешаны с новым опытом. Режим на первом входе выбирает участник. Новые три профиля/контекста и 7 дат дают 21 персона-день с конкретными усилиями, проектным сроком, переносом встречи, отсутствиями и одним офлайн-входом. Всего 17 доступных дат и 4 недоступных, максимальный бюджет 368 операций. Это условия эксперимента, а не выполненные действия и не измеренная вероятность возвращения людей.

У приложения нет регистрации/серверных процессов: каждому участнику выделяется persistent Chromium profile с отдельными локальными данными. Часы меняются только внутри браузера до загрузки. Пустой день не открывает приложение; обработка накопленного интервала происходит при следующем настоящем входе. Полные месячные/человеческие эффекты не объявлены покрытыми неделей.

## Исполняемая часть

- build_packet.py извлекает 27 runtime-ресурсов и исходный native driver из закреплённого коммита; код приложения не редактирует. Архив содержит точный runtime, шрифты/иконки, Python-зависимость, роли, мир, инструкции и манифест. Git нужен только сборщику, внешнему исполнителю он не нужен.
- Native driver LAB-005 в ZIP побайтово прежний. Новый pilot_driver.py расширяет список защищённых ресурсов двумя flex-скриптами, сохраняет/проверяет собственный хеш адаптера и читает правильный lifegame-flex-lab namespace для observer-state. Все действия продукта по-прежнему проходят UI. Ключи/кэш/scope приложения не меняются; на чистом локальном origin копия обслуживается по /personal-lab/.
- bundle.py проверяет SHA/размеры, пробует настоящий браузер, сверяет HTTP-ресурсы с архивом и собирает реальный ответ ZIP. Профили остаются в среде для продолжения, по умолчанию не пересылаются. Возвращаемый ZIP доказательств не обещает перенос рабочего браузерного сеанса.
- analyze.py читает настоящий журнал/сводку, показывает closed/active/unrun, проверяет traces и валидирует фактические сохранения через planning/flex-model/persistence в Node. FACTS не подменяет семантическую проверку намерения и независимый UX-анализ.
- smoke.py — отдельная техническая фикстура. Она создаёт данные только через видимые элементы настоящего интерфейса и хранит собственные артефакты вне опытов участников.

## Контексты и возврат

START_HERE, METHOD и PROMPT-RUNNER задают реальный порядок работы. participants/P01–P03 получают только свой профиль/текущий brief/UI/собственную память. Скрытые вероятности/обязательные клики не добавлены. Один общий диалог с тремя масками не соответствует независимости. execution-provenance фиксирует реально доступные модели/settings/контексты, неизвестное остаётся unknown. PROMPT-ANALYST/REPORT-TEMPLATE задают независимую проверку и категории доказанных ошибок/UX-наблюдений/гипотез/ограничений.

Внешняя модель должна выполнить capability check, а при недоступном коде/браузере/PNG/независимых контекстах вернуть конкретный blocked или частичный результат. Разные сервисы могут использовать ручной JSON/PNG-посредник, поскольку localhost не общий; его труд учитывается отдельно. Платные вызовы автоматически не запускаются. Ручная приёмка человека вынесена отдельно и не раскрывается слепым участникам. Готовых отзывов/журналов несуществующего пилота в архиве нет.

## Фактические проверки

Окончательный ZIP идентичен успешному candidate-02 и повторно проверен по CRC, всем 45 записям MANIFEST, всем 27 оригинальным runtime-файлам и побайтовому native driver из Git. В чистой распаковке без Git прошли verify/preflight и 9 технических групп: UI-создание привычки/пяти минут без награды, сохранение ID/времени/памяти после рестарта и новой даты, недоступный день без браузера, три изолированных профиля, неизменяющее чтение законченного опыта, отказ при изменении Flex, фактическая валидация/учёт 16 unrun дат и настоящий return ZIP без profiles. В первой попытке тест выбрал сокращённое название select; фикстура исправлена по реальному видимому «Ежедневная привычка». Ошибка не объявлена багом приложения.

Проверено на Linux/Python 3.12.14/Playwright 1.62.0/Chromium, Node записан в VERIFICATION.json. **Независимый AI-пилот и человеческая приёмка не выполнены.** Продуктовые функции/данные, исходный LAB-005, старые свидетельства и «ГИДРА» не менялись. Существующий HTML не редактировался, HTML-бекап не требовался. Архив — порученный комплект опыта, не полный репозиторий. Доставка в lab-ветку фиксируется после фактической проверки, main/Pages не обновляются.

Дополнительно в той же чистой распаковке повторены verify/preflight окончательного идентичного архива и настоящий CLI-цикл serve → клиент request/brief → finish. Он сохранил все 21 даты как unrun и выполнил ноль AI-сессий. Это проверка публичных команд запуска, а не дополнительное пользовательское исследование; артефакты /tmp/lab014-cli-check, факт записан в VERIFICATION.json.
