# Personal и параллельная LifeGame 1.1.0

11 ноября 2026. Сравнение основано на коде обоих приложений. Из присланных ZIP распакованы исходники и готовая сборка: восемь файлов release `lg/` побайтово совпадают с `source/dist/lg/`. CRC архивов проверен, SHA указан в SOURCE.json. Инструкции из README архива рассматривались как описание проекта, а не поручение заменить приложение целиком.

**Основы близки:** обе версии выросли из одного Claude-демо. Блоки → этапы → цели/действия → день → факты → пересмотр; отдельные привычки/квесты/бонусы, монеты/XP, добровольная Цена слова, Lite, демо и сопровождение. Различия уже существенны в повседневных возможностях и защите редактирования.

## Что перенесено по прямому поручению

Профили локаций действуют на Главную и день; общие разделы и карта сохраняют содержимое. Тема профиля применяется к интерфейсу в целом. Скрытое местом по умолчанию остаётся обязательством; освобождение от пропусков включается отдельно. Это правило интерфейс поясняет явно.

При переносе исправлены детали источника: искусственный годовой срок ручного места убран; границы учитывают действительные смены и дни недели, перекрытие правил и DST; политика пропусков фиксируется в дне; название места остаётся в факте после переименования/удаления. Наши Web Locks, контроль черновика и снимки наград сохранены.

## Подтверждённые технические различия

Собственные тесты источника успешно запущены: **35/35**. Они подтверждают много обычных сценариев. Дополнительные направленные проверки выявили случаи, которые этот набор не покрывает:

1. **Изменение назначенного бонуса.** Назначен ограниченный бонус «До изменения» на 3 использования; затем в магазине меняются название/тип/лимит. При выполнении выдаётся уже «После изменения», безлимитный, лимит 9. Personal сохраняет условия назначения; эта защита не заменялась кодом архива.
2. **Отмена раннего шага квеста.** Квест на 2 шага, шаг 5, финал 100: после завершения и отмены первого шага в источнике остаются 105 монет, прогресс 1/2, completed и действующий финал. Personal отменяет зависимый финал и оставляет 5 монет за оставшийся шаг.
3. **Выключение звёздочки.** В настоящем интерфейсе готового lg/index.html создано ключевое задание и нажата звезда для выключения: в сохранении key остаётся true. Причина в исходной tx: false трактуется как отмена всей операции. Personal уже исправляет это и переключает флаг в обе стороны.
4. **Граница ручной локации.** Правило только на четверг 23:58–23:59, текущая дата среда 11 ноября: исходная nextBoundary возвращает 23:58 среды. В переносе граница означает настоящую смену действующей локации; отдельно проверены перекрытия и повтор часа при DST.

Защита вкладок тоже устроена по-разному: источник сравнивает номер ревизии и обновляет состояние по storage; Personal дополнительно держит Web Lock на операцию и проверяет снимок данных и ревизию открытого редактора. Число тестов между версиями напрямую не сравнивается: состав сценариев разный.

Практический вывод: нет необходимости выбирать приложение целиком по одному признаку. Оформление/локации/подсказки перенесены ранее; согласованные дополнительные удобства реализованы в 1.2.0 с собственными защитами. Не требуется заменять приложение целиком.

Полная сквозная проверка источника и многомесячная эксплуатация здесь не повторялись. Реальные данные пользователя не использовались; испытания шли в изолированных контекстах с блокировкой внешних запросов. Результат проверок объединённой версии — TESTING.md.
