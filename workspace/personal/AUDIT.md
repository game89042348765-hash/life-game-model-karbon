# Сверка Personal 1.2.0 с согласованным обновлением

11 ноября 2026. Источник — код Personal на базе Claude, предыдущий рабочий runtime 3a362e0, начало этой задачи 98de9d9 (с переданными пакетами). Пользователь разрешил все согласованные изменения; это уже реализация, не первоначальное сравнение. Прежняя документация сохранена в истории.

| Требование | Реализация и проверка |
|---|---|
| Полная/простая стратегия, блоки/этапы/цели, история и пересмотр | Прежняя логика сохранена; сквозной UI гитары и сессии трёх уровней пройдены |
| Повторы daily/weekly/days/monthly/yearly | planning.js, номинальная и реальная даты, конец месяца/високосные годы проверены |
| Один перенос / это и следующие | Исключения и разделение серии, выбор будущего появления в UI; прошлое, оплаченное и отдельные будущие переносы сохраняются |
| Каждый пропуск самостоятельный | Позднее выполнение сегодня с исходным occurrence, перенос/архив; защита от повторной оплаты во всех точках |
| Дневная норма привычки | 1–50, прогресс без оплаты, одна выплата за полную норму, цель считает успешные дни; изменения нормы завтра, снимок награды |
| Зависимые отмены | Финал квеста/дневная и пороговая награды, снимки бонусов, использованный приз и средства защищены; порог не снимается без потери основания |
| Новая цель внутри редактора | Черновик вместе с действием, отмена без сироты, квота с сохранным черновиком и успешная повторная попытка |
| Цели в быстром добавлении | Четыре основных типа, «Ещё», контекст, набросок во «Входящих», конвертация, первый связанный шаг; реальные клики/reload |
| Вечер | 119 различных текстов (часть используется несколькими категориями), прогресс этапа/цели/квеста и частичная практика, один сохранённый текст дня, наград за просмотр нет |
| Напоминания | 0/15/60/1440, до часа после, квитанция на появление; часовые границы, перезапуск, чужая локация пройдены |
| Визуализация награды | Сохранение до эффекта +N/плавного баланса; сбой записи эффекта не даёт, reduced motion — мгновенный итог |
| Копии/экспорт | last-good и начало дня, датированный просмотр/скачивание/подтверждение замены; сбои и повреждение не стирают исходный файл, экспорт/7 дней/позже на 3 дня |
| Импорт | Earn/reversal и facts 1:1, spend/refund без XP; строгая схема, нет ремонта денег или автосмешения lg-4 |
| Стили/локации/подсказки/Lite/демо | Прежние функции сохранены, три темы и локальные шрифты офлайн; ночные графики и DST; старый v2 без пересчёта ledger/facts |
| Защита хранения | Guard/tx/очередь/Web Locks/snapshot/revision, две вкладки, квота основной/резервной записи, импорт/экспорт и управляемое обновление |
| Установка | Scope только personal, оболочка v5 включает planning.js и читает свой кэш; настоящие offline reload/выполнение/обновление |
