# LifeGame — 30 самостоятельных миров продвижения

Готовая галерея: [strategy-worlds-30.html](../../downloads/strategy-worlds-30.html).
Это один автономный HTML, без библиотек, шрифтов, внешних запросов и хранилища.
Кнопка **↓ HTML** скачивает все 30 вариантов. Основное приложение и прежняя
галерея из 11 стилей не меняются.

Первые пять миров исследуют свет: маяк, оптическую призму, рассвет, созвездие
и перспективу раскрывающихся комнат. Остальные 25 используют другие устройства
пространства и материала: сад, острова, полотно, город, склон, механизм, оригами,
метро, партитуру, мозаику, гончарную форму, шлюзы, книгу, кухню, молекулы,
пусковую конструкцию, гексагональное поле, лифт, песок, пресс, танец, монтаж,
домино, лабиринт и скульптуру.

Это не переключение оформления общей вертикальной ленты. Для каждого мира
написаны две собственные композиции: весь маршрут и работа внутри этапа.
Элементы самих миров интерактивны. Общая внешняя панель помогает сравнивать
варианты и воспроизводить события. [Матрица](MATRIX.md) описывает их причинность.

## Как пробовать

- Выберите мир в списке, стрелками или верхними кнопками.
- Нажимайте элементы в мире либо нижние тестовые кнопки.
- Два дела подготавливают завершение этапа. Возврат пропущенного независим.
- Завершите этап и нажмите «Открыть следующий этап». Предыдущий остаётся в истории.
- Пройдите три этапа либо сбросьте выбранный мир для повтора.
- «Сценарий» за 21 секунду показывает два этапа, включая восстановление пропущенного.

Вкладки используют общее состояние. При переключении мира прогресс каждого
сохраняется в памяти открытой страницы. Перезагрузка начинает заново.
Отмена разворачивает физическое движение вклада и убирает его постоянный след.
Завершение оставляет отдельное изменение материала/пространства.
Настройка reduced motion пропускает хореографию, сохраняя конечное состояние.
Временные эффекты останавливаются при сбросе, смене мира/вкладки, изменении
ширины окна и скрытии страницы. Изменение высоты мобильной панели браузера
само по себе не прерывает движение.

## Сборка и структура

```sh
python demo/strategy-worlds/build.py
```

- `catalog.js` — 30 концепций и смысл событий.
- `scenes.js` — 60 самостоятельных SVG-композиций, встроенные элементы действий.
- `materials.js` — постоянные следы восстановленного и завершённого.
- `motion.js` — хореография каждого мира, обратное движение отмены и очистка.
- `app.js` — тестовые факты, вкладки, история трёх этапов, галерея и скачивание.
- `worlds.css` — оболочка, типографика, адаптация и доступность.
- `build.py` — сборка всех исходников в один HTML без зависимостей.

Взяты смысл и API исходного `downloads/stage-animation-template.html`.
`StageDemo.completeTask / completeStage / reset / setTab / getState` и события
`demo:task-complete / task-undo / stage-complete / reset / tab-change` сохранены.
Состояние расширено тремя этапами, историей и переходом.
`StrategyWorlds` предоставляет `worlds`, `setWorld(id)`, `getWorld()`, `getState()`,
`play()`, `stop()`, `nextStage()`, `getEffects()`. Фрагмент URL, например `#loom`,
открывает конкретный мир.

Условные награды 25/50/25 — только для воспроизводимости. Реальные данные,
сохранения, экономика, API и окна LifeGame не используются.
