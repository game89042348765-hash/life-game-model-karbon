# LifeGame — 11 вариантов движения к цели

Это отдельная галерея, а не изменение приложения. Готовый автономный файл:
[`downloads/strategy-animation-lab.html`](../../downloads/strategy-animation-lab.html).
Откройте его в браузере или скачайте кнопкой **↓ HTML**. Сеть и сервер не нужны.

В каждом варианте есть вкладки «Этапы» и «Внутри текущего», выполнение и отмена
тестового дела, возврат невыполненного, завершение этапа и сброс. Кнопка
«Сценарий» последовательно показывает два шага, возврат невыполненного и
прохождение этапа. Награды и прогресс условные, только в памяти страницы.

| № | Вариант | Что означает движение |
|---|---|---|
| 1 | Гелиос | Искра от дела питает большое солнце |
| 2 | Атлас | Новая звезда соединяется с созвездием маршрута |
| 3 | Призма | Усилие преломляется и собирается у цели |
| 4 | Маяк | Сигнал зажигает следующие вехи |
| 5 | Сияние | Нить действия вплетается в общий поток |
| 6 | Сад | Семя даёт рост, пройденный этап раскрывается цветком |
| 7 | Конструкция | Дело становится модулем, этап собирается в пролёт |
| 8 | Тушь | Действие продолжает штрих, этап закрепляется печатью |
| 9 | Импульс | Действие передаёт движение следующему звену |
| 10 | Течение | Капля вливается в поток, уровень накопленного растёт |
| 11 | Контур | Свет проходит по рамкам этапов вниз, на линии остаётся продвижение |

В «Контуре» камера сопровождает реле света. Ручной скролл/движение пальцем
отключает сопровождение. Во всех вариантах смена вкладки, темы, сброс и скрытие
страницы очищают временные эффекты. Системная настройка уменьшения движения
отключает хореографию и сразу показывает конечное состояние.

## Исходники и сборка

Основа — существующий двухвкладочный `downloads/stage-animation-template.html`.
`lab.css` задаёт 11 визуальных языков, `lab.js` — галерею и хореографию. Сборка
не требует пакетов:

```sh
python demo/animation-lab/build.py
```

Не редактируйте сгенерированный HTML вместо исходников. Чтобы передать другой
модели все варианты, достаточно одного готового HTML.

`window.StageDemo` сохраняет API основы. Дополнительный `window.DesignLab`
позволяет выбирать вариант (`setTheme('contour')`), проигрывать сценарий
(`playSequence()`), останавливать эффекты (`stop()`) и читать их состояние
(`getEffects()`). Фрагмент URL `#contour` сразу открывает одиннадцатый вариант.
Анимации не пишут в localStorage, не вызывают API и не начисляют реальные награды.
