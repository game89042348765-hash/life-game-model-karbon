# LifeGame — схема сценария

Готовый автономный файл: ../../downloads/lifegame-flow-schematic.html.
Тёмная мобильная схема без карты и анимаций. Два способа: пройти создание
с нуля по подсказке либо загрузить готовый вымышленный гитарный пример.
Полная/простая стратегии, этапы, задания с четырьмя расписаниями и тремя
независимыми настройками, отдельные квесты/привычки, Конструктор дня,
достижения и ручное получение бонусов. Условные демобаллы не связаны
с валютами приложения. Всё состояние только в памяти страницы.
Флажок и расписание определяют состав дня; связь с целью и фокус его
не меняют. Привязка к этапу даёт контекст. Завершение этапа ручное,
прежние дела не удаляются. Кнопка HTML скачивает исходную страницу.
Рабочие index.html/assets, localStorage и виджет «Ключевые действия» не используются.
