# Новая LifeGame

Отдельное рабочее приложение новой концепции. Адрес после публикации: https://game89042348765-hash.github.io/life-game/next/ . Прежнее приложение остаётся по корневому адресу.

## Начало

При первом открытии есть восемь пустых направлений. Создай свой блок или открой базовый → выбери текущий этап → добавь смысл, цели и действия. Разреши нужным действиям участвовать в Конструкторе. Во вкладке «Сегодня» выбирай темп, выделяй ключевые задания и выполняй дела. Привычки, квесты и календарь также доступны самостоятельно во вкладке «Действия».

«Ещё» открывает входящие, быстрый поиск и выполнение, магазин, решения, ништяки, итоги, пересмотр, инструменты, историю, архив и настройки. В инструментах различаются каталог, «Мои» и размещение в дне. Закрытие этапа предлагает выбрать судьбу каждой оставшейся активности.

Начальная установка **без примеров, демо и обучения** по последнему поручению пользователя. Их будем проектировать после приёмки основы. ИИ пока обозначен отдельным экраном без подключения внешней модели.

## Сохранения

Автосохранение в этом браузере: `lifegame-next-v1`; предыдущая исправная копия: `lifegame-next-last-good-v1`. Старые ключи не читаются и не изменяются. JSON из настроек содержит всё новое состояние; восстановление заменяет новую жизнь целиком после подтверждения. Старый формат не импортируется. Другой браузер или устройство получит данные только после переноса этого файла.

Скачивай резервную копию из настроек для собственного хранения. Локальное сохранение зависит от доступности и объёма хранилища браузера; серверной синхронизации пока нет. Напоминания работают при открытой странице, фоновые уведомления после её закрытия не реализованы.

## Локальный запуск

Из корня репозитория: `python -m http.server 8027 --bind 127.0.0.1`, затем http://127.0.0.1:8027/next/ . Нужен HTTP(S): ES-модули не рассчитаны на запуск двойным щелчком через `file://`. Сборщик и сетевые зависимости приложению не нужны.

## Устройство

| Файл | Назначение |
|---|---|
| `domain.js` | Чистая модель, команды, расписания, события, экономика, проверка формата |
| `store.js` | Отдельное хранилище, очередь, Web Locks, проверка устаревшей записи, резервная копия |
| `app.js` | Экраны, полноэкранные редакторы, выбор бонусов, действия пользователя |
| `style.css` | Мобильное оформление и уменьшение движения по системной настройке |
| `messages.js` | Сто поддерживающих текстов в пяти группах |
| `tests/` | Проверки модели, недели и граничных сценариев интерфейса |

## Проверки и документы

Модель: `npm test --prefix next` из корня. Браузер: запустить HTTP-сервер, установить Python Playwright и Chromium, затем `python next/tests/week.browser.py` и `python next/tests/edges.browser.py`. Скрипты используют `/usr/bin/chromium`; адрес можно задать через `LIFEGAME_TEST_URL`. Они открывают отдельные контексты с вымышленными данными и блокируют внешние запросы.
