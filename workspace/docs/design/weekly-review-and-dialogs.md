# Недельный обзор и адаптивные окна

Согласовано 7 ноября 2026. Два направления в одном поручении пользователя, основной index.html.

## Недельный обзор

«Мой ритм» раскрывает обзор сохранённых результатов недели. Шесть показателей: выполненные дела, минуты, шаги квестов, завершённые квесты, цели, дни с результатом. Это дополнение системного weekRhythm, отдельный виджет не создан. Соседние недели используют прежнюю навигацию; доступна и неделя, где есть только вечерний итог.

Повторные переносы показываются по eveningReviews: две и более разные даты с tomorrow/later. Только незавершённые once-дела активных блоков. Открытие карточки помогает пользователю самостоятельно уточнить шаг/план; автоматических переносов, штрафов и начислений нет. На экране объясняется источник переносов. История без соответствующих вечерних записей не восстанавливается догадками.

Минуты: keyActions.entries плюс recorded focusLog без actionId. Связанные receipts не считаются второй раз; удалённая entry не заменяется старым receipt. Результаты и их отмена следуют rhythmFacts. Будущие дни исключены, единица ритма — дата с фактом, не количество событий. Обзор не пишет данные, JSON и миграции прежние.

## Окна

Общий lg-adaptive-dialog применяется в uiShowDialog ко всем HTML-диалогам, сохраняя специализированный чат и нижнее подтверждение наград. Размер и положение следуют visualViewport.height/offsetTop. Изменения viewport обрабатываются через один requestAnimationFrame на кадр; активное поле прокручивается в видимую область. Лимит редактора использует те же значения и safe-area.

Компактные отступы/подписи, удобные кнопки от 44 px и ввод 16 px. Числа в две колонки при достаточной ширине, на 320 px — в одну. Тип квеста и валюта имеют один понятный уровень выбора вместо вложенных рамок. Нативные radio/checkbox 20 px внутри строки не менее 44 px; текстовые поля и значения сохранены. Смысл: начальная высота 110 px, основное действие выделено золотом. Специализированные формы/архив/чат/ритуал сохраняют состав действий. Нативные confirm/alert/prompt браузера остаются прежними: их синхронные защиты не менялись косметическим патчем.
