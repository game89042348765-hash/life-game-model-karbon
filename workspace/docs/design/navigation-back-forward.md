# Навигация — прежнее меню и возврат в логотипе

8 ноября 2026. После тестирования пользователь отменил отдельные верхние Назад/Вперёд и нижние стрелки прокрутки: они ухудшили впечатление от приложения. Прежний контракт сохранён в `docs/history/2026-11-08-before-calendar-links/navigation-back-forward.md`.

## Действующий интерфейс

Прежняя шапка LIFE / GAME и балансы восстановлены. Жёлтая точка рядом с логотипом заменяется небольшой стрелкой, когда доступен возврат. Её нажатие возвращает на предыдущий экран. Если возврата нет, точка декоративная, кнопка недоступна и скрыта от accessibility tree. Псевдоэлемент расширяет зону нажатия вокруг маленькой видимой иконки.

Нижнее меню снова исходное: Главная / Блоки / Квесты / Бонусы, без добавленных боковых стрелок и полосы прокрутки. Отдельной кнопки Вперёд в приложении нет. Демо `demo/navigation-controls.html` оставлено как исторический материал, не описывает текущий интерфейс.

## Сохранённый безопасный механизм

Единая History API, один экранный переход текущего открытия, UI-кэш прокрутки/этапа/вида блока/даты календаря и раскрытия «Запланированного». Закрытые формы не открываются снова через native Forward. Новый переход после Назад отбрасывает ветку Вперёд. Reload создаёт новую границу; старые native-записи не становятся целями стрелки текущего сеанса.

Системные Back/Forward работают с этой историей; изменённый редактор защищён прежним подтверждением. История возвращает только UI, не отменяет выполнение/награды/переносы. В недоступном History API обычные переходы сохраняются, точка не становится активной стрелкой.

Проверен один возврат через логотип, native Forward, переход по календарному тегу и возврат к быстрому добавлению с сохранённым черновиком, отсутствие добавленных панелей и четыре исходных раздела на 320/390/430 px. Пользовательская приёмка и реальный iPhone отдельно.

Уточнение 8 ноября: лимит стрелки уменьшен с пяти до одного возврата. Штрих 3 px, визуальное выравнивание поднято на 1 px к центру точки. Системная история браузера не удаляется.
