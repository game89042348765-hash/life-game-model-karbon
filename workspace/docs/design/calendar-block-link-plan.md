# Календарные дела, блоки и недавние записи — внедрённый контракт

8 ноября 2026. Пользователь разрешил реализацию календарного этапа вместе с пятиминутным показом и игровым откликом. Прежний план сохранён дословно в `docs/history/2026-11-08-before-calendar-links/calendar-block-link-plan.md`.

## Одна запись календаря

`calendarEntries[].blockId` — необязательная ссылка на блок, null без связи. При загрузке старого JSON отсутствующее поле становится null. Неизвестный ID/неправильный тип отклоняется до сохранения; существующий архивный блок допустим. ID календарной записи, дата/время, completionId и прежние наградные журналы остаются источником истины.

Блок выбирается и при быстром добавлении с датой, и в полном редакторе календаря. Связь можно снять/изменить. В выполненной записи дата/время/награда блокируются до отмены; имя/заметка/связь доступны. Перенос даты сохраняет ID и открывает выбранный день календаря после сохранения. Перенос связи не начисляет наград.

На карточке календаря есть тег блока. Активный тег открывает нужный блок и находит запись; архивный тег виден, но не ведёт в недоступный блок. Метаданные календаря с датой/временем видны во всех представлениях.

## Секция блока

«Запланированное» — сворачиваемая служебная секция перед рабочим путём блока. Она отображает связанные календарные записи: Ранее / Сегодня / Далее, сортировка по дате и прежним правилам времени/избранного; выполненное — в свёрнутой истории. Здесь есть добавление по дате с заранее выбранным блоком.

Секция не является элементом `blockStages`: нет целей/смысла, текущего состояния, блокировки или участия в прохождении. Календарные записи доступны независимо от текущего этапа. В `tasks` дубликаты не создаются. Счётчик блока «Дел / На сегодня» включает незавершённые календарные записи и прежние активные задания.

Архив блока сохраняет запись в календаре/Конструкторе и связь с архивным блоком. Восстановление возвращает секцию. Новую связь с архивным блоком назначать нельзя; существующую можно оставить или снять. UI окончательного удаления блока в приложении отсутствует — новый разрушительный сценарий не добавлялся. Импорт с отсутствующим блоком отклоняется, календарная запись не отбрасывается молча.

## Выполнение и история

Все представления вызывают прежний `completeCalendar` для одного ID. Положительная награда — одна монетная запись, нулевая — только факт выполнения. Повторное выполнение не платит дважды; отмена использует прежний факт и защиту потраченного баланса. Удаление карточки сохраняет прежнюю политику факта/начислений с предупреждением и невозможностью отмены через удалённую карточку.

Сегодняшний календарный раздел Конструктора показывает дела на сегодня. «Выполнено» отбирает календарные дела по фактическому дню выполнения, включая досрочно завершённые будущие записи. В секции Задания второй копии нет. Бонус дня не расширялся на календарь.

## «Недавно добавлено» — пять минут

В игровом JSON добавлен необязательный `recentCaptures`: массив `{kind:'task'|'calendar',id,until}`. Это ссылки без копирования названий/дат/наград/фактов. Их создают быстрое добавление с блоком/датой, обычное создание распределённого задания/календарной записи и распределение входящего дела через перенос/редактор. Без блока и даты задание остаётся во входящем списке бессрочно, включая «Сегодня» без блока.

Срок 300000 мс от сохранения/распределения, абсолютный until. Reload не перезапускает отсчёт. Нормализация убирает истёкшие, слишком далёкие по времени и потерявшие источник ссылки; повреждённая структура/дубли отклоняются. До 1000 временных ссылок, по одной на kind/id. Привязка ранее нераспределённой календарной записи начинает новый пятиминутный показ; обычное редактирование уже связанной записи не продлевает его.

Быстрое добавление показывает распределённые дела обычными taskCard/calendarCard под формой, без заголовка «Недавно добавлено», отдельной компактной версии и сворачивания «Ещё». Штатные действия работают с оригиналом. Ненавязчивый срок показа остаётся; через 5 минут исчезает только эта проекция. Секундный таймер обновляет фрагмент, не пересоздаёт форму и введённый текст.

## Игровой отклик

Отклик сохранения стал заметнее: контрастный малый индикатор с типом записи/галочкой, 2,1 с, без кнопок/затемнения/перехвата фокуса. По возможности используется manual popover, чтобы отклик был виден и поверх возвращающегося диалога. После быстрого добавления кнопка на 650 мс показывает галочку; форма уже сброшена к исходному состоянию.

Двухнотный короткий сигнал 740 → 990 Гц отличается от наградного звука, играет только после успешного сохранения и уважает общую настройку звука. Аудио разблокируется пользовательским жестом, ошибки Web Audio не влияют на данные. Частые события ограничены по звуку; визуальный одиночный индикатор перезапускается. Reduced motion отключает анимацию. Подтверждения отмены и эффекты реальных наград сохранены.

## Проверено и ограничения

Node: миграция/валидация ссылок, архивный блок, TTL/reload/исчезновение без удаления объектов, отсутствие копий/изменения журналов, дубли/невалидные ссылки. Прежние тесты этапов/путей проходят.

Изолированный Chromium на вымышленных данных: 320/390/430 px, быстрый и полный ввод с/без блока, тег/секция/Конструктор, перенос даты/блока и снятие связи, однократная награда/отмена/нулевая награда/защита потраченных монет, архив, старые данные и настоящий валидный/невалидный импорт, три недавних/«Ещё»/expiry с сохранённым вводом, reload без перезапуска срока, quota/конфликт snapshot, звуковой sink/выключение/уменьшение движения, старое меню и возврат через логотип. Ошибок JS/внешних запросов/недостающих ресурсов нет.

Физический iPhone, реальное восприятие звука и пользовательская приёмка отдельно. Реальные пользовательские данные не открывались и не заменялись. При переносе кода локально нужен новый runtime-файл `assets/calendar-links.js`; ZIP без отдельной просьбы не создавался.


Уточнение последующего этапа: Запланированное перенесено в общую линию после текущего и показывает даты от сегодня. Просроченные невыполненные записи видны в Невыполненном и календаре; прошлые выполненные — в календаре. Раздел Ранее в Запланированном отменён. Полный действующий порядок: [centered-block-path.md](centered-block-path.md).
