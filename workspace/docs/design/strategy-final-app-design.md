Дата: 8 ноября 2026 года. Задача пользователя: взять `strategy-final-concept.html`, надеть дизайн приложения, сохранить функционал шагов 1–4, временно отключить карту. Предыдущий вариант `strategy-optimized.html` не выбран в качестве основы: он изменил подход сильнее, чем пользователь хотел.

## Результат

Отдельный самостоятельный HTML: `demo/strategy-final-app-design.html`.

Ссылка для проверки: https://game89042348765-hash.github.io/life-game/demo/strategy-final-app-design.html

Это исходное демо с другим оформлением. Данные/анкеты/примеры, алгоритм построения уровней, правила открытия, переходы, добавление/редактирование, переключение карточек и отметки не заменены новой моделью.

## Оформление

- Токены графита и жёлтого акцента из настоящего `index.html`, системный шрифт, бренд LIFE / GAME и демонстрационные счётчики.
- Настоящие SVG-иконки приложения: сердце, физическое состояние, книга, кошелёк, отношения, компас и другие. Цветные иконки блоков, нейтральные фоны без бокового свечения.
- Четыре исходных шага: «1 Блоки / 2 Анкета / 3 Итог / 4 Блок». Анкета не заменена сокращённым новым сценарием.
- Графитовые карточки/поля/кнопки, жёлтые действия, нижние окна с постоянными видимыми кнопками в прокручиваемой области.
- Смысл и цели визуально отделены серыми поверхностями `#303030` / `#282828` и знакомыми фиолетовой/голубой иконками.
- Рабочая карточка сохраняет «сейчас», цели, дела, исходную точку, ближайшие этапы, оптимальный, скрытые уровни, дальний максимум и листание блоков.

## Карта отключена

Пятый шаг удалён из навигации. Все ссылки «На карте» убраны из отображаемого интерфейса. Обработчики входа в карту не открывают её, сохранённый ранее `view=map` переводится в карточку блока или список. Координаты и прежние данные карты не удаляются. Сам код карты оставлен неактивным для отдельного дальнейшего обсуждения.

Изменены лишь связанные с картой подписи демонстрационного заполнения, чтобы не отправлять пользователя в недоступный экран.

## Данные и границы

Используется **тот же ключ исходного концепта** `lifegame-strategy-concept-v1`: уже сохранённый пример открывается в новом оформлении. Формат данных прежний; демонстрация не читает и не меняет реальный прогресс LifeGame. Одновременная работа разных вкладок не получила новой синхронизации — это прежнее поведение исходника.

Функционал исходных шагов сохранён буквально: полная анкета из шести экранов, короткая из пяти уровней с обязательным названием оптимального, будущие этапы только с описанием, цели/дела в текущем, последовательный переход с первоначальной семантикой условий. В этой задаче не вводились перенос рутин, новые условия по целям, новая экономика и другие механики из оптимизированного демо.

Не исправлялись и не объявляются решёнными ранее найденные ограничения исходного прототипа: пустые дела следующего этапа, простая отметка done вместо датированного прогресса, упрощённая запись в Storage и условия без новой валидации. Это сознательная граница задачи «дизайн без смены функционала». Основное приложение, загруженный оригинал и предыдущее оптимизированное демо побайтово сохранены.

## Проверки

Изолированный Chromium, вымышленные данные; внешние запросы блокированы. Основной сценарий — 390×844, дополнительные размеры — 320×568, 430×932, 1000×800. Снимки просмотрены.

**Парное сравнение:** одинаковые действия выполнены в оригинале и новой версии, сохранённое состояние совпало во всех 13 контрольных точках:

2. Добавление цели/дела и отметка задания.
3. Та же отметка из рабочей карточки.
4. Редактирование будущего и вставка этапа.
5. Удаление вставленного этапа.
6. Заполнение остальных блоков примерами.
7. Блокировка перехода условием другого блока.
8. Достижение требуемого этапа.
9. Разрешённый переход к следующему.
10. Добавление смысла/цели/дела нового текущего этапа.
11. Свой блок «Гитара», короткая анкета, 5 уровней.
12. Настоящий touch-свайп карточек и отметка.
13. Reload с тем же состоянием.
