## Что изменилось

- Убран виджет Стратегии: реестр, стартовое размещение, избранное/каталог, страница карты и её UI-код/стили. Старый адрес экрана ведёт в Блоки. Остальные виджеты и их настройки сохраняются.
- Внутри настоящего блока — лестница по образцу выбранного демо: Фактический → текущий → Планируемый → Оптимальный → Неизвестный. Есть полный вариант с этапом перед оптимальным и максимумом. Число реальных этапов не ограничено фиксированными 5/7.
- «Описать путь» даёт короткую/полную анкету. Она редактирует описания и ориентиры вокруг существующих данных; не заменяет цели/задачи, не генерирует награды и не удаляет ранее созданные этапы.
- Текущий этап содержит прежние настоящие карточки смысла, целей и заданий. Сохраняются повторы, награды, избранное, связь с целью, Конструктор дня, история, архив/порядок, выполнение и отмена.
- «Блок времени» переключает к рабочему виду с настоящими карточками; «Все этапы» возвращает лестницу. Настройки вида только в памяти страницы.
- Можно добавлять этапы **перед** текущим и **после** него, а также вокруг любого другого этапа. Стабильные ID и текущий этап не меняются. Запись, добавленная назад, не считается автоматически достигнутой или пройденной.
- Кнопки вставки этапов и действия вставки в меню скрыты по умолчанию. Они появляются при открытой шестерёнке блока и скрываются при её закрытии; смена блока и reload сбрасывают этот режим. Правило одинаково для лестницы и рабочего вида.
- «Этап пройден → следующий» использует подтверждение. По выбору отмечается предыдущий этап пройденным; цели/дела не выполняются автоматически, награды за сам переход не выдаются.
- Сохраняются ручное закрытие и условие «дойти до другого этапа». Неизвестный/максимум дополнительно закрыты до факта достижения оптимального. Вход в оптимальный ничего не начисляет.
- Содержимое старых будущих/прошлых этапов не скрыто без доступа: есть переход к их настоящим карточкам в режиме подготовки/истории. Незавершённые дела/цели выполняются только в текущем этапе. Старое выполнение можно отменить прежним механизмом с защитой потраченных валют.

## Данные и совместимость

`blockStages` v2 расширяет прежний канонический объект:

- `items`: прежние id/blockId/name/meaning/reached/lock + description, levelKind (stage/optimal/hidden/maximum), slot (служебный маркер шаблона или null), passed.
- `current`: прежняя карта blockId → stageId.
- `paths`: mode (short/full), fact, configured по blockId.

Старые стадии/цели/задания остаются с теми же ID и связями. При миграции вокруг них добавляются детерминированные заготовки; новые записи не получают completed/reached сами собой. Миграция повторяемая без дублей. Смысл блока остаётся совместимым зеркалом текущего этапа.

`reached` означает хотя бы раз был текущим; `passed` — отдельно подтверждённое прохождение; completedDate и completion — реальные прежние результаты/записи наград. Эти факты не подменяются положением в списке.

Проверка циклов включает явные условия и неявное «оптимальный → горизонт». Неизвестные ссылки и текущий закрытый этап отклоняются. Перестановка/вставка не меняет ID зависимостей. Запись через прежний transact, без обхода ошибок/конфликтов.

`widgets` v10 удаляет только размещение/избранность strategy, оставляя остальные пункты. Старое `data.strategy` сохраняется в JSON для обратимого восстановления прежних данных, но не используется виджетами или картой. Его проверяет небольшой `assets/legacy-data.js`; прежние UI-модули удалены. Новые копии с blockStages v2 требуют обновлённого кода. Код из ZIP до изменений рассчитан на свою прежнюю схему; ZIP не заменяет отдельный JSON прогресса.
