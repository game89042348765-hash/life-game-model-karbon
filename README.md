# life-game-model-karbon

Отдельная рабочая песочница для внешней модели. Основной репозиторий LifeGame здесь не заменяется; его публичность при импорте не менялась.

## Начать работу

1. Прочитай [START_HERE.md](START_HERE.md) и конкретное задание пользователя.
2. Исходники уже распакованы в [workspace/](workspace/). Вводная — [workspace/00_START_HERE.md](workspace/00_START_HERE.md), шаблон задания — [workspace/01_TASK_FOR_MODEL.md](workspace/01_TASK_FOR_MODEL.md).
3. Для изменения создай отдельную ветку `task/описание`, сохрани исходные пути и верни Pull Request в этот репозиторий с описанием и фактическими проверками.

**Готовый ZIP:** [LifeGame-Developer-Pack-2026-11-13.zip](packages/LifeGame-Developer-Pack-2026-11-13.zip), около 15,8 МБ. [Происхождение и SHA](IMPORT_SOURCE.json). Архив сохранён в исходном виде; для разработки используй workspace/.

Срез включает основную Personal, родительскую лабораторию, Базовый/Полный, AI-прототип, Next и прежний root. Это разные приложения с разными данными; выбирай область по заданию. Полной Git-истории и старых архивов нет. Бекапы/профили/тяжёлые traces исключены; ограничения отдельных исторических тестов отмечены во вводных.
