# LifeGame Hybrid v2.0 — Готовый пользовательский релиз (Лайт и Про)

Завершённое автономное приложение для ежедневной жизни без перегруза, штрафов и выгорания. Объединяет спокойную эстетику и воздух первой версии (`Root v1`) с инженерной глубиной `Personal 1.2.0` по принципу двух калькуляторов.

## Эволюция релизной линейки
- **v1.0 (Базовая сборка ветки от Этапа 0)**: чистый переключатель `[ Лайт | Про ]`, бонусы в Лайт, «Карта жизни» строго под «Конструктором дня» в Про, 7-дневные тихие точки частичных минут (`F-001`), серии календаря, квесты, `LifeGame AI`, конвертер `Personal 1.2.0`.
- **v1.1 (Жизненный цикл и реальное время)**: автопереход даты по реальным часам устройства в пространстве «Моя жизнь», полное редактирование/архивация/удаление всех сущностей через аккуратные нижние шторки, выгрузка встреч `.ics` в календарь телефона и мгновенная кнопка `↩ Отменить` в уведомлениях.
- **v1.2 (Живая Карта и поиск)**: торжественное завершение текущего этапа сферы (`🏆 Этап пройден`) с переносом в достижения основания и продвижением следующего этапа, перетаскивание сфер на Большой карте, настройка цвета/природы сферы и мгновенный поиск по делам и архиву.
- **v1.3 (Бережный вход для нового человека)**: мастер старта за 60 секунд при первом открытии, встроенный «Карманный путеводитель», спокойный график недели/месяца без красных счётчиков вины, локальные напоминания о встречах и индикатор свежести резервной копии.
- **v2.0 (Финальный релиз)**: свои локации и автовыбор контекста по времени суток, копирование тёплого итога недели в 1 клик, синхронизация между вкладками браузера (`storage` listener), печатный стиль и полная автономная проверка SHA-256.

## Запуск и передача другому человеку
1. **В один файл**: отправь человеку файл `standalone/lifegame-hybrid-v2.0.html` — он открывается в любом мобильном или настольном браузере полностью офлайн и сразу встречает мастера старта за 60 секунд.
2. **Как устанавливаемое PWA на GitHub Pages**: распакуй архив в репозиторий и опубликуй ветку — локальные шрифты `woff2`, иконки и `sw.js` работают без единого внешнего CDN.
